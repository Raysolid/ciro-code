## Open Core boundary

<div class="home-callout">

**Kernel and CLI are fully open source** — local execution is auditable. **Web UI and official Profiles ship as npm install artifacts** so the project can stay sustainable. **Your config, keys, and sessions stay on your machine** and are never uploaded without your permission.
