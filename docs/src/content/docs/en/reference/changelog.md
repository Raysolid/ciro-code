## 0.1.x

- Local Web workbench via `ciro web`
- Modes: Ask / Plan / Agent / Debug
- Feature Packs (`ciro pack add`)
- Mock backend for install smoke tests (`--mock`)
- Product directories under `.ciro` / `~/.ciro`

Check the installed version:

```bash
ciro -V
npm view @ciro-code/code version
```
