---
title: 工作模式
description: 按任务选择 Ask、Plan、Agent 或 Debug。
---

模式回答的是：**此刻 Agent 该怎么干活？**  
模型回答的是：**用哪颗模型** — 在设置里配置。

## 按意图选

| 场景 | 模式 | 会发生什么 |
|------|------|------------|
| 解释代码、摸清仓库、不改文件 | **Ask** | 偏只读，默认更安全 |
| 大改之前先想清楚方案 | **Plan** | 规划向；降低误改风险 |
| 实现功能或修 bug | **Agent** | 可在策略下改文件、跑命令 |
| 追查失败或缺陷 | **Debug** | 接近 Agent，偏诊断 |

可随时在工作台切换模式，也可启动时指定：

```bash
ciro web --mode ask
ciro web --mode agent
```

## 使用建议

- 不熟仓库时先用 **Ask**。
- 改动大或风险高时用 **Plan**。
- 提交前务必看 **Changes**。
- 敏感命令仍可能弹出确认 — 这是预期行为。

完整 CLI 参数见 [命令行参考](/reference/cli/)。
