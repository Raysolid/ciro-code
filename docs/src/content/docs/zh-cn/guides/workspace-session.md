## 工作区

工作区是 Ciro Code 可读取（以及按模式可写入）的项目根目录。可在 UI 选择，或传 `-w`：

```bash
ciro web -w /path/to/project
```

未传 `-w` 时，若目录仍在，下次启动会尽量恢复最近工作区。

## 会话

- 发送**第一条消息**时才创建会话。
- 启动时会清理空会话。
- 历史保存在本机产品目录（见下）。

## 落盘路径（用户可见）

| 路径 | 用途 |
|------|------|
| `{workspace}/.ciro/` | 项目配置、记忆、规则、计划 |
| `~/.ciro/` | 用户配置、密钥、Pack、会话 |

迁移期内仍可能读取旧的 `.pi` / `~/.pi/agent`。有旧数据时用 `ciro doctor` 与 `ciro migrate` — 见 [CLI](/reference/cli/)。
