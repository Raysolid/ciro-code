Ciro Code 在你的机器上运行：带策略沙箱的编码助手，以及本地 Web 工作台。

## 从这里开始

1. [安装](/getting-started/install/)
2. [快速开始](/getting-started/quickstart/)
3. [配置模型](/getting-started/first-provider/)

```bash
npm install -g @ciro-code/code
ciro web
```

工作台：[http://127.0.0.1:3080](http://127.0.0.1:3080)
