# @ciro-code/ext-git

官方 Feature Pack：安装并启用后，右栏出现 Git 面板（状态 / 变更列表，只读 MVP）。

```bash
ciro pack add @ciro-code/ext-git           # npm latest
ciro pack add @ciro-code/ext-git@0.1.1     # 指定版本
ciro pack add @ciro-code/ext-git --from packages/ext-git  # 本地

# 然后在 Settings → 功能扩展 中启用
ciro pack list
```
