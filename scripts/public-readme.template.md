# Ciro Code

Local coding agent harness — policy-aware tools, session memory, and a streaming HTTP API you can run on your machine.

> Prefer editing `docs/opensource-README.md` (export source of truth). This file is a fallback template only.

## Install (npm)

```bash
npm install -g @ciro-code/code
# same as: npm install -g @ciro-code/cli
ciro web --mock --no-open
```

Windows (pwsh) and macOS use the same commands. See `docs/opensource-README.md` for Open Core boundary and from-source build.
